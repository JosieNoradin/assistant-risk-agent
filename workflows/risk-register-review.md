# Workflow: Risk Register Review

## Objective
Review an Excel risk register and identify records requiring attention.

## Input
Microsoft Excel risk register (.xlsx)

## Procedure
1. Open the supplied risk register.
2. Validate the expected columns.
3. Read all active risks.
4. Identify missing or incomplete information.
5. Identify high-exposure risks.
6. Summarise proposed changes.
7. If material changes are required, present the proposed changes and ask
   the user for approval before applying them.
8. If no material changes are required, proceed without requesting approval.
9. Save the reviewed workbook as a new file. Never overwrite the original
   workbook unless explicitly instructed by the user.

## Rules
- Never delete risks without approval.
- Never overwrite the original workbook.
- Never invent missing risk information.
- Flag uncertainty to the user.
